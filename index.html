Docs

Read the fine print

How does contract make my address?

Your browser creates real Ed25519 keypairs, encodes each public key in base58 and checks it against your letters. It runs on every CPU core you have, in parallel, until one matches. The first match is yours.

Do my keys ever leave my device?

No. Generation happens in your browser tab. The private key is shown only to you and never stored or sent. Copy or download it before you close the window, because it cannot be recovered.

Which characters can I use?

Solana addresses use base58: digits 1–9 and letters except 0, O, I and lowercase l. Each extra character makes the search about 58 times longer (about 34 times when capitalization doesn't matter).

How do I launch the mint on Pump.fun?

Pump.fun mints end in "pump", so keep that as your suffix. Download the keypair file and import it into a launch tool that accepts a custom mint keypair. The keypair signs the mint creation once, then the address is your coin's CA.

What formats can I export?

A base58 secret key that Phantom and Solflare import directly, and a JSON byte array that the Solana CLI reads as a keypair file.

What do I pay for?

Wallet patterns up to 3 characters are free. Longer patterns and token mints carry a small platform fee in SOL, sent from your connected wallet before the search starts. Network and Pump.fun launch fees are separate.
